**Objective:** Design and develop a graph database-driven web application that models interconnected data within a chosen problem domain, demonstrating the practical advantages of Neo4j over relational and other NoSQL data models.

**Context:** Select one of the following domains as the focus of your application. Your system must reflect real-world entities, relationships, and data flows relevant to the domain. The use of Neo4j should be justified by the inherently connected nature of the data.

* Disaster Risk Reduction and Climate Adaptation  
* Agriculture and Food Systems  
* Environment and Natural Resources  
* Health and Epidemiology Systems  
* Public Safety and Security

**Requirements:**

1. Develop the backend using Neo4j Graph database.  
2. Build a fully functional web application with the following core features:  
   * User authentication (Login/Logout) *(Optional)*  
   * CRUD operations (Create, Read, Update, Delete) for data management  
   * Search functionality for easy data retrieval and navigation  
   * Data visualization (dashboard) to present stored information effectively   
3. Implement backup feature using JSON file download.

**Bonus:** Additional points will be awarded for extra features and enriched content beyond the core requirements.

**Deliverables:**

1. **Project Context** – A written description (in paragraph form) explaining the problem, the proposed solution, and its intended users.  
2. **Working Web Application** – A fully functional prototype demonstrating all required features.  
3. **Class Presentation** – A live demonstration and walkthrough of the application.  
4. **Source Code** – A GitHub repository link containing the complete source code.
